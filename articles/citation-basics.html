APA, MLA 인용 형식, 헷갈릴 때 보는 기본 정리

전공마다 요구하는 형식이 다르니, 먼저 어떤 형식을 써야 하는지부터 확인하세요.

논문이나 리포트에 참고문헌을 표기할 때 형식을 잘못 쓰면 감점 요인이 되기도 합니다. 전공에 따라 요구하는 형식이 다르므로, 지도교수나 학과의 안내를 먼저 확인하는 것이 우선입니다.

어떤 전공이 어떤 형식을 주로 쓸까

형식주로 쓰이는 분야
APA심리학, 사회과학, 교육학, 경영학
MLA문학, 언어학, 인문학 일부
시카고(Chicago)역사학, 일부 인문학
IEEE공학, 컴퓨터공학
Vancouver의학, 생명과학

APA 형식 기본 (학술지 논문 기준)

저자명(발행연도). 논문 제목. 학술지명, 권(호), 페이지. 의 순서로 작성합니다. 저자가 여러 명이면 마지막 저자 앞에 &를 붙이는 것이 특징입니다.

MLA 형식 기본

저자명. "논문 제목." 학술지명, 권.호, 발행연도, 페이지. 의 순서로 작성하며, 논문 제목을 큰따옴표로 묶는 것이 APA와 다른 점입니다.

가장 흔한 실수

  • 같은 리포트 안에서 형식을 섞어 쓰는 것 — 처음부터 끝까지 하나의 형식으로 통일해야 합니다.
  • 저자가 여러 명일 때 표기 순서를 임의로 바꾸는 것 — 원문에 표기된 저자 순서를 그대로 따라야 합니다.
  • 온라인 자료인데 접속 날짜나 URL을 빠뜨리는 것 — 웹 자료는 형식마다 URL·접속일 표기 규칙이 다르므로 확인이 필요합니다.
참고 — RISS, DBpia 같은 사이트는 논문 페이지에서 인용 형식(APA, MLA 등)을 자동으로 생성해주는 기능을 제공하는 경우가 많습니다. 직접 형식을 맞추기보다 이 기능을 활용하면 실수를 줄일 수 있습니다.
